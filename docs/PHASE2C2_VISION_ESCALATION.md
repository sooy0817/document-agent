# Phase 2-C2 Vision Escalation — 설계만, 미구현

착수 조건은 (1) 독립 사람 검토 표본, (2) Text 경로의 실패/기권 사유 기록,
(3) 전송할 crop 범위와 모델/예산에 대한 승인, (4) 패치 검증 회귀 통과다.
이미지 기반 감사보고서는 Text 호출을 하지 않고 `requires_ocr_or_vision`으로 남긴다.

대상 사유: native text 부재, 글자 위치가 여러 셀을 가로지름, 미관측 배경색/폰트가
필수인 구조, 불확실한 외곽/병합 경계, 복수 패널 후보, 페이지 연결 음성 증거 부족.
먼저 OCR과 Vision 중 필요한 경로를 선택한다. 둘 모두 이번 C1 구현에는 없다.

입력은 source_document hash, page/crop bbox 및 변환, 기존 cell/node allowlist,
읽기 전용 Physical/Structured IR 참조, 로컬 특징과 충돌 후보다. 기본 전송은 표 전체가
아닌 문제 영역과 필요한 인접 문맥이다. 원본 PDF 첨부와 무제한 재시도는 금지한다.

출력은 기존 ID를 참조하는 구조 제안/기권이다. 숫자/원문/새 셀/bbox 생성 금지,
독립 스키마와 ID·패널·페이지 체인·순환·점유 범위·원문 불변성 검증을 적용한다.
모델의 확신이나 스키마 통과를 정답으로 취급하지 않는다. 기존 run을 덮어쓰지 않는다.

평가는 개발과 동결 holdout, 실제 PDF와 합성을 분리하고, Text-only 대비 추가 개선량,
잘못된 확정률, 기권률, 비용/시간을 독립 골든에서 측정한다. 회계 Fact 및 Template
Matcher 연결은 별도 단계다. 사람 검토가 없으면 결과는 계속 provisional이다.
