# Phase 2-C 계획 — 이번에는 구현하지 않음

1. 독립 사람이 실제 4페이지 전체 관계/경로를 판정한다. 8페이지 비병합 들여쓰기,
   14페이지 등급/금리 하위 행 및 다열 값 범위를 우선한다. 비농협 실제 PDF를
   개발용/동결 평가용으로 분리하고 합성 성적과 합산하지 않는다.
2. 원문 span의 상대 정렬·들여쓰기·스타일을 후보 근거로 보강한다. 항목명·연도·제목
   사전을 범용 구조 모듈에 넣지 않는다. 패널/연속표의 음성 사례도 검증한다.
3. Vision 입력은 원본 IR, 허용 ID, 모호성, crop bbox를 포함한다. 현재 max_calls=0
   변경은 별도 ADR/실행 정책 이후다. 향후 허용 시에도 표당 국소 호출 최대 1회,
   타임아웃·거절·잘못된 ID·근거 없는 응답은 unresolved 유지, 무한 재시도 금지다.
4. 패치는 스키마·ID·근거·점유·순환·패널·충돌을 검증한다. 숫자/텍스트/셀/bbox 생성은
   금지한다. 제안을 정답으로 승격하지 않으며 새 run에 부모 run/patch/판정자를 기록한다.
5. 전체 행/열 edge precision/recall, 경로 정확도, abstention, 잘못된 확정 비율을
   독립 정답에서 측정한다. 목표 수치는 독립 baseline 이후 설정한다. 라벨 교체,
   패널 음성, 이미지 PDF, 유도문구 및 Phase 2-A/2-B 회귀를 완료 gate에 포함한다.

이번에는 입력/제안 스키마와 ID membership 검사만 제공한다. LLM 호출/라우터/패치
적용 엔진은 없다. Template Registry/Matcher, 표준화, PostgreSQL Fact는 별도 범위다.
