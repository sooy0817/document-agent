# 오류 사례 담기

1. http://127.0.0.1:8766/ 에서 저장 문서를 연다.
2. 오른쪽 표에서 잘못된 셀을 클릭한다. 셀 상세의 **이 셀 오류 담기**를 누른다.
3. 오류 유형을 고르고, 필요하면 원본에서 어떻게 보여야 하는지 메모한 뒤 저장한다.
4. 전체 표 문제는 **클릭해서 선택할 범위 → 표 전체 선택**으로 바꾼다. 셀을 눌러도 해당 표 전체가 선택된다. 중첩표는 **담을 표 전체** 목록에서 안쪽/바깥쪽을 선택한 뒤 **이 표 전체 오류 담기**를 사용한다. 내부 표가 빠졌다면 바깥 셀/표를 담고 내부 표 누락을 표시한다.
5. 추출된 표 자체가 없으면 기존 검증 사례의 **선정 영역 오류 담기**를 사용한다. 새로운 자유 영역 드래그는 아직 제공하지 않는다.
6. 왼쪽 **오류 사례 보관함**에서 다시 열기, 메모 수정, 제외/복원, ZIP 다운로드를 한다.

각 사례는 `work/document-explorer/error-basket/<id>/`에 저장된다.
원본 선택 영역 이미지, 셀 선택 시 표 문맥 이미지, 실제 선택 표의 PhysicalTableIR,
원시 StructuredTableIR(저장된 실행이 있는 경우), Canonical 구조, 중첩 연결 및
원본/Canonical 해시를 함께 보존한다. 셀만 고른 경우에도 경로 판단을 위해
해당 표 전체를 문맥으로 포함한다. 전체 원본 PDF나 API 키는 ZIP에 넣지 않는다.

원본 snapshot은 불변이고 메모·제외·복원은 별도 이벤트 파일이다. 같은 원본/실행/대상을
다시 담으면 사례 수를 늘리지 않고 피드백 이력을 추가한다. 다른 추출 버전은 별도 사례다.
오류 종류와 메모는 사용자의 주장으로 저장하며 정답으로 자동 승인하지 않는다.

모든 항목은 아직 `training_ready=false`다. 수집한 오류만으로 정답을 학습할 수는 없다.
정답 구조를 작성하고 원본 근거를 검토한 뒤, 모델 입력/목표 출력으로 변환하는 후속 단계가
필요하다. 이번 기능에는 파인튜닝, 프롬프트 자동 반영, 파서 수정, Gold 자동 승인이 없다.
피드백을 개발에 사용했다면 그 문서는 더 이상 미사용 Holdout이 아니다. 기존 평가 기록은
그대로 두고 이후 평가의 데이터 분리를 별도로 관리한다.

검증: `python -m pytest demo/test_error_basket.py demo/test_demo.py -q -k "not image_input_preserves"`
기존 이미지 변환 테스트 2개는 알려진 PyMuPDF 이미지 프로필 오류로 이 변경의 검사에서 제외했다.
실제 PDF의 행·열 의미 정확도는 이 UI 테스트의 검증 범위가 아니다.


## 정답 참조 작성 (2026-11-03)

담기만 하면 메모와 원본 저장이 완료된다. 편집기는 자동으로 열리지 않는다.
원할 때 **연결까지 지정하기 (선택)** 또는 보관함의 **정답 참조 작성**으로 연다.
이미 저장한 메모·선택 대상이 표시되며, 최초 작성 시 메모를 판단 이유에 이어준다.

1. 왼쪽 원본에서 페이지와 선택 종류(셀/표/문장)를 고른 뒤, 영역이나 목록을 클릭한다.
2. **판단할 셀 / 연결 시작으로**를 눌러 대상을 지정한다.
3. **셀 역할**에서는 현재 잘못된 역할과 올바른 역할을 고른다.
   관계 판단에서는 끝 대상을 선택하고 **연결 대상으로**를 누른다.
   **연결해야 함 / 연결하면 안 됨**을 구분한다.
4. 근거가 있는 셀·문장·페이지를 고르고 **원본 근거로 추가**를 누른다.
   다른 페이지도 지정 가능하다. 인용은 원문 일부로 줄일 수 있지만 바꿔 쓸 수 없다.
5. 이유를 쓰고 **이 판단 목록에 추가**한다. 한 사례에 여러 판단을 넣을 수 있다.
6. 알 수 없는 내용은 **불확실**로 표시하고 그 이유만 기록할 수 있다.
7. **정답 참조 저장**을 누른다. 작성 중인 판단도 목록에 반영해 함께 저장한다.

수정할 때는 목록의 **수정**을 누른다. 이전 참조는 별도 이력으로 유지되며 ZIP에 포함된다.
불확실 판단은 참조 초안과 구분된다. 저장해도 training_ready=false이며, 자동 학습·
모델 프롬프트 반영·추출 JSON 변경은 없다. 원본이 달라졌거나 다른 창에서 먼저 저장하면
충돌을 알려주고 기존 기록을 덮어쓰지 않는다. 아직 임의 영역 그리기는 지원하지 않으므로
추출이 없는 곳은 페이지 근거와 위치 설명으로 기록한다.
