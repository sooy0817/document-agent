# 집계 범위와 합계 검증 기준

사용자 확인 기준: 2026년 10월 19일. 남원 개발셋 검산에 적용했으며 향후 평가의 명시적 검산 정책으로 재사용한다.

## 계산과 원문 보존

- 원본 셀이 확인된 대시 `-`와 빈칸은 합산에서 0으로 계산한다. 원문 문자열과 좌표는 변경하지 않는다.
- 셀을 찾지 못했거나 원문 추출이 실패한 경우는 빈칸과 구분한다. 미연결 셀은 0으로 처리하지 않는다.
- 계산 정책, 적용된 원본 셀 ID, 합산 대상, 계산값, 표시 합계, 차이를 별도로 기록한다.
- 금리·비율은 단순 합산하지 않는다. 음수는 부호를 유지한다. 지원하지 않는 숫자 표기는 보류한다.
- 계산 불일치를 없애려고 값을 바꾸거나 항목을 제외하지 않는다. 일치 여부와 무관하게 같은 계산 정책을 적용한다.
- 현재 정확 일치를 기준으로 한다. 반올림 허용 오차는 원문 단위와 반올림 근거를 확인한 후 별도 정책으로 정한다.

## 정답지 검토 순서

1. 원본에서 그룹 제목, 병합 영역, 기간, 단위, 집계 대상의 포함·제외를 확인한다.
2. 상세 합산 시 상세와 소계를 중복 계산하지 않는다. 총계가 소계들로 구성되면 해당 범위를 명시한다.
3. 원본 셀에서 가져온 수치로 합계를 계산한다.
4. 산술 일치와 구조 검토 상태를 따로 기록한다. 합산 일치만으로 부모 관계나 Financial Fact를 확정하지 않는다.
5. 불일치 또는 미확인 근거는 검토 대상으로 유지한다. 정답 변경은 원본 정답을 보존한 별도 revision으로 관리한다.
6. 같은 정답과 정책으로 자동 결과를 다시 평가하여 경로 개선과 회귀를 확인한다.

## 현재 결과와 다음 작업

남원 7개 표의 기존 검토용 집계 범위에서 금액 열 40건을 계산했다. 39건 일치, 1건 불일치, 보류 0건이다. p46 당기 요적립액의 상세 합계는 3,656,615이고 표시 합계는 3,656,616이다. 차이 1의 원인이 반올림인지 아직 확인하지 않았다.

이 결과는 집계 범위의 산술 근거이며, 60개 셀 경로 불일치가 해결됐다는 의미는 아니다. 다음 순서는 병합 소계·합계 행의 셀 연결, 표 밖 부모의 전파, 동급 행의 잘못된 부모 연결, 독립 비율 행 및 정답 셀 영역 대응 검토다. 실제 범용 수정은 항목명·페이지별 정답 하드코딩 없이 수행한다.

남원은 개발·회귀용으로 유지한다. 새 문서 평가 전 코드·설정·정책을 동결하고, 문서에 별도의 공란·대시 정의가 있으면 충돌을 기록한다. 남평은 미사용 최종 Holdout으로 유지한다. 새 LLM 호출 및 RAG 모델 실험은 별도 승인 범위로 관리한다.
