# 자동 표 구조 개선: 실제 팀 구성과 다음 단계

## 현재 실행 흐름

1. `web/app.py`의 자동 평가 API가 작업을 시작한다.
2. `teams/campaign/service.py`가 로컬 수집과 공개 자료 후보 검색을 실행한다. 이 수집은 현재 Supervisor 그래프 밖에서 실행된다.
3. `teams/campaign/graph.py`의 규칙 기반 Supervisor가 개발·회귀 표본을 `services/documents.py`의 처리기로 넘긴다.
4. 처리된 문서마다 `teams/campaign/review.py`가 저장된 결과를 자동 점검한다. OCR 필요 페이지, 미검증 표, 불확실한 셀 경로를 출처 ID와 함께 남긴다.
5. 전문 검토 연결 지점에서 멈춘다. 점검 신호는 오류 확정도, LLM 검토 결과도, 정답도 아니다.

최대 20개 표본을 처리하며 holdout은 읽지 않는다. 로컬 수집함은 `data/campaign-inbox` 바로 아래 PDF만 찾는다. 공개 목록의 자료는 후보 링크만 기록하고 PDF 다운로드나 자동 처리는 아직 하지 않는다.

## 다음 연결 순서

1. 점검 신호를 전문 검토 요청 형식으로 변환하는 어댑터: 원본 해시, 페이지, 표·셀 ID, 이미지 근거를 검증하고 중복 요청·예산을 제한한다. 신호가 없다고 구조가 정확하다고 판단하지 않는다.
2. 전문 검토 결과를 개선 요청으로 묶는다. 출처가 없는 추측이나 사용자 승인 상태를 만들어내지 않는다.
3. 기존 파서 실험과 비교 기능에 개발·회귀 자료의 고정된 버전을 전달한다. 결과는 후보로만 보존하고 기존 파서를 자동 교체하지 않는다.
4. 변경에 사용하지 않은 holdout으로 별도 평가한다. 정답이 없는 자료의 처리 성공과 정확도 검증을 구분한다.
5. 출처·이용 조건을 기록하는 외부 표본 수집기와 크기·건수·중복·권한 정책을 설계한다. 데이터 역할은 수집 시 자동으로 확정하지 않는다.
6. 작업 상태 복구, 중복 실행 방지, 비용·시간 제한을 영속화하고, 화면에 팀별 판단·근거·중단 사유를 상세히 보여준다.

사람 검토는 자동 후보 생성과 실험·회귀 검증 뒤에 진행한다. 사용자 판단은 원본 근거와 대상 버전에 연결해 저장하고, 검증되지 않은 자동 신호를 정답으로 승격하지 않는다. 승인된 파서 후보를 미사용 문서에 재검증한 뒤 새 실패 사례를 다음 개선 작업으로 연결한다. 이 검토·승인·재검증 루프는 아직 연결되지 않았다.

비교 모듈은 동일 데이터셋·기준 정답 해시·지표 버전과 동일 분모에서만 결과를 비교한다. `reference_status`는 호출자가 제공하는 값이므로 현재 자체적으로 사람 검증 이력을 인증하지 못한다. 실제 평가 화면에 연결하기 전에 기존 사람 검토 기록과 연결해 확인해야 한다.

## 기록

캠페인 상태는 `work/campaigns/campaigns.sqlite3`, 문서 결과는 각 표본 폴더, 자동 점검은 `campaign-review.json`에 저장한다. 점검 파일은 `result.json` 해시와 원본 셀·표 ID를 기록한다. 자동 점검 성공은 문서나 수치의 검증이 아니다.

## 2026-11-04 팀 연결 업데이트

- 공식 후보 중 국토연구원 상세 페이지에 출처표시 문구와 직접 PDF 링크가 있는 경우만 PDF를 받아 개발 표본으로 등록한다. 크기·암호·파일 형식·해시를 검사하고 출처 페이지, 파일 주소, SHA-256, 관찰한 이용 조건과 수집 일시를 기록한다. 한국은행은 이용 조건을 확인하지 못해 링크만 남긴다. 상세 페이지가 JavaScript 다운로드 방식이면 미지원으로 기록한다.
- 개발 표본의 자동 점검 결과를 원본 해시와 결과 해시 검증 후 기존 error-basket 및 review-queue 요청으로 만든다. 문서별 한 표당 한 요청, 캠페인당 최대 5건이다. 회귀·holdout 표본은 개발 피드백에 넣지 않는다. 각 요청은 로컬 근거 검사만 수행하며 LLM 전문 검토는 실행하지 않는다.
- 이전 설명 중 국토연구원 PDF 다운로드가 미구현이라는 설명은 위의 제한된 다운로드 경로에 한해 대체된다. 전문 LLM 검토, 파서 개선, 회귀 평가와 사람 최종 확인 루프는 아직 미연결이다. 실제 외부 사이트 HTML 및 네트워크 접근은 환경 DNS 문제로 검증하지 못했다.
