# ADR-076: 질문별 근거 판단과 원문 연결 검사를 분리

- 상태: 채택
- 날짜: 2026-11-10

## 배경

RAG가 고정 수치 질문 단어와 1900~2099년 정규식으로 근거 충족 여부를 판단했다.
문장형 답변도 조건·예외·최신성·적용 범위를 특정 표현으로 분류했다. 이 방식은
새 언어·분야의 질문을 누락하고 본문 숫자나 표 텍스트를 불필요하게 제한한다.

## 결정

1. 사전 검사는 근거 ID·원문 존재·표 매핑 사용 가능 여부와 명시적 출처 제약만 담당한다.
2. 기존 답변 모델의 한 응답에 질문 조건별 판단과 답변을 함께 요구한다. 조건은 질문의
   원문 구간에 연결하고, 판단은 supported/unsupported/ambiguous로 기록한다.
3. 조건의 근거는 source_id, 필드, 원문 인용으로 표현한다. 코드가 실제 출처·질문 구간·
   선택 근거와 대조하고, 불충분·모호·외부 확인 필요 또는 연결 오류면 답변을 보류한다.
4. 본문·표·주석·단위·머리말·부모 문맥을 출처 목록으로 제공한다. 표의 텍스트와 본문의
   숫자를 동일하게 허용한다. 미해결 표 매핑은 여전히 차단한다.
5. 문장별 원문 인용·숫자·조건 절 보존 검사는 유지한다. 자연어 단어 목록으로 의미를
   인증하지 않는다. 적용 범위 판단과 질문 분해의 완전성은 모델 후보로 남긴다.

## 대안과 결과

- 단어 목록의 확장은 중단한다. 설정 파일로 사전을 옮기는 것만으로 범용성을 얻지는 못한다.
- 별도 모델 검토 호출은 도입하지 않는다. 기존 한 호출 안의 자기 판단은 독립 검증이 아니다.
- 검색어 재작성 계획은 선택적 가설이며 SQL 필터나 검증 완료 조건으로 사용하지 않는다.
- 의미적으로 틀린 인용 연결, 빠뜨린 질문 조건, 잘못된 적용 판단을 코드만으로 모두 탐지할
  수 없다. `semantic_entailment_verified=false`를 유지하며 미사용 문서·질문의 실제 모델
  평가와 정답 근거 비교가 필요하다.
- 선택형·문장형 모델 응답의 assessment는 필수다. 이전 응답과 호환되지 않지만 최종
  selection 형식, 파서 IR, 저장 DB 스키마는 유지한다.
- 질문 판단이 필요하므로 과거의 일부 키워드 기반 호출 전 보류는 모델 호출 후 보류로
  바뀐다. 출력 한도 2,400토큰과 기존 비용·입력 한도, 외부 호출 허용 조건을 적용한다.
- 의미 불충족에 대한 자동 재호출은 하지 않는다. Agent의 사전 검사 실패 재검색만 유지한다.
- Hybrid RAG, 파서의 의미 경로 개선, 독립 모델 평가·사람 승인은 별도 작업이다.
