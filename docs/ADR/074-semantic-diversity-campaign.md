# ADR-074 — 동결 IR 기반 표 구조 다양성 캠페인

- Date: 2026-11-05
- Status: Implemented first bounded cycle; full improvement loop incomplete

## 결정

`teams/semantic_campaign`이 기존 CampaignStore, 공개 자료 수집기,
의미 비교 서비스, 규칙 gate, 실제 역할/관계/Judge 서비스를 연결한다.
파서 동결은 계속 적용한다. 기존 문서·오류 큐는 입력으로 보존하며
신규 결과와 전문 검토는 독립된 캠페인 폴더에 기록한다.

LangGraph의 단계는 inventory → collection → processing → selection →
candidates → specialists → validation이다. 기존 IR의 구조 신호로 부족한
유형을 계산하고 부족한 경우에만 요청된 공개 수집을 시도한다.
현재 수집기는 기존 공식 목록 두 곳을 최대 한 건씩 조회하고 PDF 한 개까지만 받는다.
유형을 웹 검색어로 변환하는 탐색 및 금융 PDF 다운로드 확대는 미구현이다.

명시적으로 선택한 기존 문서는 개발 자료로만 사용한다. 등록된 회귀/holdout
파일 해시는 거절한다. 형태 해시는 정확히 같은 격자의 중복 표본을 줄이는
후보 신호이며 동일 양식 판정이 아니다. 가족/양식 확인과 미사용 평가 분리는
아직 미완료이므로 holdout 성능을 표시하지 않는다.

## 경계와 예산

- 기존 입력 최대 20문서, 선정 최대 40표, 유형 목표 최대 10표.
- 새 공개 PDF 최대 1개, 80쪽 제한. 처리 시 동결 무결성 검사.
- LLM 대상 기본 1셀, 최대 4셀. 셀별 gate와 기존 호출 예산 적용.
- `table_review.service.execute(budget_data=...)`는 독립된 증거 폴더를 쓰되
  기존 서비스의 일별 예산 원장을 공유한다. 활성화 설정은 변경하지 않는다.
- 외부 수집 실패는 기록 후 기존 자료로 진행한다. 전문 검토 실패는 추가
  모델 대상 실행을 중단하며 인간 검토 패킷은 미완료 상태를 명시한다.
- 소스/코드/단계 해시를 고정하고 OS 파일 잠금으로 동시 실행을 방지한다.
  완료 단계는 재개 시 재사용한다. 호출 전 dispatch를 기록하며 완료 증거가
  없는 중단 호출은 자동 재시도하지 않는다. 완전한 트랜잭션 outbox는 아니다.

## 사람 검토와 평가

별도 HTML에서 원문·기존·후보와 호출 결과를 확인한다. 후보 해시에 묶인
표 단위 correct/incorrect/uncertain JSON 판단을 append-only로 저장한다.
이는 검토 의견이며 cell/axis 정답 reference의 승인, 정확도 재채점, 규칙 승격이
아니다. 기존 모니터 UI 버튼 연동은 아직 없다.

현재 의미 개선 팀은 기존 규칙 후보의 재생·비교를 실행한다. 새 규칙 코드 자동
생성/적용은 하지 않는다. 후보 정답률·오연결률 및 회귀 점수는 확정 reference와
평가 연결 후 계산한다. 모델 응답 실패를 모의 응답으로 대체하지 않는다.
