# ADR-061: 오류 담기부터 사용자 판단·재검토까지

2026-11-04. 기존 Folio/SQLite 검토 큐를 재사용한다. 파서 자동 수정은 제외한다.

신규 오류 이벤트만 agents_roles 모드로 자동 실행한다. 활성화 이전 기록은 이전 모드를
유지하며 자동 재처리하지 않는다. roles 실험 모듈은 그대로 호출하는 어댑터로 연결한다.
한 실행은 최대 3호출, 기존 일일 한도를 유지한다. 원본 변경/범위 초과/예산 부족은 보류한다.

사용자 판단은 요청별 불변 decision 레코드다. 일치/수정 필요/근거 부족, 이유, 원문 ID를
저장하고 같은 원본 스냅샷으로 자식 요청을 한 번 만든다. 중복 전송은 같은 자식 ID를 반환한다.
수정된 판단은 새 재검토 결과에서 다시 제출한다. 역할 단계는 사용자 판단을 보지 않고,
관계/검수 단계는 이를 검증할 주장으로 받는다. 사용자 판단은 자동 Gold가 아니다.

DB 트랜잭션 안에서 판단과 자식 요청을 같이 저장한다. 이전 결과·파서·IR을 덮어쓰지 않는다.
원본/JSON 해시를 다시 확인한다. 단계별 체크포인트를 재사용하며 무한 자동 재검토는 없다.

대시보드 알림은 사례별 최신 요청의 실패·보류·오류 후보에 한정한다. 정상 범위 내 이상
미검출과 진행 상태는 전체 기록에 남긴다. 페이지 내 알림만 제공하며 운영체제 푸시는 아니다.
재검토의 경로 변화, 검사 오류 변화, 비용을 비교하되 정답 정확도 향상으로 표시하지 않는다.
판단 입력 중 폴링으로 폼을 지우지 않는다. 원본 확인과 기존 정답 참조 편집기를 연결한다.
