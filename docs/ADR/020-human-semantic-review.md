# ADR-020: Human semantic review preparation

Status: additive implementation, 2026-10-20.

Frozen IRs and DescriptionBundle 0.1 are unchanged. A versioned review-pack sidecar identifies 14 deliberately selected development cases and questions, immutable baseline hashes, description IDs and evidence IDs. Every saved review captures the question snapshot, pack hash and review protocol. Existing events remain readable; no earlier approvals are reclassified.

Assisted source comparison is not independent blind annotation. These reviews remain development Gold candidates until a separate reviewer confirms final Gold. Candidate selection, final Gold and publication gates remain distinct. No numeric match promotes semantic truth. Analytical interpretations remain hypotheses.

Numeric diagnostics are a separate read-only view of the same saved operations. Primary cause categories are mutually exclusive; secondary tags may overlap. Arithmetic differences are observable, while rounding and incorrect semantic scope remain hypotheses unless independently checked. Blank and triangle policies are not changed. Ratios with different denominators require scope review even if money sums match.

Description edits display incident relations, operations and affected subjects as potential impact. This is reference-based dependency inspection, not prose understanding. Human reviewers must inspect whether changed prose conflicts with those dependencies. Source values, source PDFs and original bundles are unchanged.

Remaining: authenticated reviewers, blind independently authored answers and adjudication, context-qualified definition reuse, immutable publication snapshot assembler, approved automatic Agent runner, and matched independent/rule-assisted evaluation. This work adds none of these execution services.
