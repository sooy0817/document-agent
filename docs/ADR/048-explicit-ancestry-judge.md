# ADR-048: B 방식의 명시적 축·상위 관계 검사

2026-10-29. 기존 A Judge·생성기·파서·IR·Canonical·DB는 보존한다.
새 B는 같은 원본/후보에서 각 축의 존재 상태, 직접 제목, 상위 제목, 누락·과잉 제목,
근거 ID와 문맥 상태를 반환한다. 단일 모델 호출이며 새 생성/교정/대량 큐는 없다.
ID 유효성·목록 집합 차이·누락인데 만점/unknown인데 확정 점수 같은 모순은 코드가 검사한다.
이 검사는 의미 정답을 보장하지 않으며 모든 결과는 검토 후보다.

A/B는 동일 모델 gpt-4.1-2025-04-14, 동일 원본·후보·이미지·출력 예산 4000으로 비교한다.
기존 A의 과거 실행(출력 예산 2500)도 보존하되 새 paired A/B를 우선 비교한다.
Gold와 파일명·기관명별 분기·예상 판정은 모델 입력에 넣지 않는다.
새 문서는 B 구현/프롬프트 동결 후 확보하며 결과를 본 후 모델 코드를 수정하지 않는다.
추출 실패·후보 없음·API 실패·Judge 출력 불일치는 각각 분리하여 분모에 남긴다.
계속표는 제공된 영역만으로 이전 헤더를 알 수 없으면 unknown이 정상일 수 있다.
이번 버전은 외부 페이지의 새로운 헤더를 자동 복원하지 않는다.

원본 이미지로 참조를 작성하되 새 문서 점수는 자동 보조 검토 기준이며 독립 사람 Gold로
주장하지 않는다. 모든 평가 이력 및 API 사용량은 새 경로에 저장한다.
