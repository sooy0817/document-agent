# ADR-064: 원본 관찰을 먼저 받는 검토 화면

2026-11-04 · 로컬 검토 UI 변경. 파서·모델 프롬프트·저장 IR 변경 없음.

## 문제

원시 검사 코드와 모델의 경로 후보가 사용자 판단 양식 앞에 노출되어,
사용자가 무엇을 확인해야 하는지 알기 어려웠다. 내부 표의 부모 연결 및
중복 표시 문제와 모델 응답의 인용/누락 오류도 같은 목록으로 보였다.

## 결정

- 원본 비교 → 관찰 유형 선택 → 전달할 문장 미리보기 순서로 안내한다.
- 중첩 위치, 중복, 누락, 읽기 순서, 행열 연결을 복수 선택한다.
- 정상/불확실 의견은 선택 범위에만 적용하며 문서 전체 승인으로 쓰지 않는다.
- 모델 경로와 모든 검사 로그는 별도의 접힌 참고 영역에 보존한다.
- 기존 `choice/note/source_ids` 계약을 유지한다. 선택 내용을 note에 직렬화해
  기존 결정 API와 불변 자식 재검토 요청을 재사용한다. 신규 Gold 필드가 아니다.
- 문서 화면에서 기존 검토 대상 셀을 선택하면 양식 대상에도 연결한다.
  목록 밖의 셀 ID를 임의로 전송하지 않는다. 범위 밖은 별도 담기를 안내한다.
- 단순 선택이나 미리보기는 모델 호출/저장하지 않는다. 저장 버튼에서만
  기존 일일 예산과 최대 호출 횟수를 적용한 재검토가 실행된다.

## 한계와 검증

유형별 안내와 구조 그림은 공통 설명용이며 문서에 대한 자동 진단이 아니다.
실제 표시/부모 연결/물리 추출/의미 관계 원인은 후속 검토에서 구분한다.
이번에는 UI·전달 문장·대상 ID 연결을 검증했다. 모델 품질 실험은 하지 않았다.
기존 큐/기록/IR은 수정하지 않았으며 사용자 관찰 예시는 화면 초안으로만 남겼다.

검증: JS 9건, pytest 3건 통과. 최초 pytest 실행은 제한 환경에서 대기하여
해당 프로세스만 종료하고 같은 검사를 재실행했다. 실제 브라우저에서 복수 선택,
전달 미리보기, 원본 셀 강조, 같은 화면 유지, 개발자 로그 접힘을 확인했다.
