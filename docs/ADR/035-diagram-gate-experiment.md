# ADR-035 — 도식 후보의 표 의미 분석 보류 실험

2026-10-27. Opt-in experiment, production disabled.

## 범위와 계약

기존 CanonicalDocument / PhysicalTableIR / StructuredTableIR / 원문은 불변.
Physical 후보가 생긴 뒤 SemanticTableAnalyzer 직전에 사용할 독립 gate를 추가한다.
실험은 기존 Physical 결과를 입력으로 재생하며 PDF 재추출, OCR, LLM, RAG, DB 변경은 없다.
새 sidecar만 원본 ID, 좌표, 근거 선 ID, 처리 결정을 저장한다.

## 규칙

- stroke 또는 기존 Physical의 fill-transition 선으로 네 변 94% 이상 지지되는 셀만 폐쇄 셀 근거로 사용.
- 1.5pt는 기존 포함 관계 평가의 좌표 오차 허용값. 서로 3pt보다 떨어진 폐쇄 셀의 변 내부를 잇는 선을 연결선 후보로 기록.
- 셀 세 개 이상에 두 개 이상의 중복되지 않은 연결선이 있으면 도식 후보. 이름, 페이지 번호, 텍스트 키워드, 기대 셀 수는 입력하지 않는다.
- 도식 연결 성분 외의 폐쇄 셀이 같은 Physical 후보에 있으면 혼합/불확실로 보류. 다른 Physical 후보는 독립 처리.
- 연결선 없이 공통 변을 공유하는 폐쇄 셀은 표 후보로 기존 의미 분석에 전달. 이는 의미 검증 승인이 아니다.
- 연결선 하나 또는 부족한 격자 근거는 unknown으로 보류. 원본·텍스트를 삭제하지 않는다.
- 경계가 끊긴 표, 선 없는 표, 단일 셀을 보류할 수 있다. 기본 운영 적용하지 않는다.
- 영상 도식, 곡선/직각 다중 선분 연결, 화살표 글리프, 절차 의미는 이번 최소 규칙에서 인식하지 않는다.

## 평가

기존 한국어 12문서 300쪽 및 농협/PNEUMA/LH Canonical 재사용.
기존 24개 선정 영역과 부분 Gold는 평가에서만 읽고 탐지 함수에 전달하지 않는다.
이전 Holdout은 이미 열람되었으므로 이번에는 전부 재사용 회귀 자료이며 독립 일반화 성능으로 표시하지 않는다.
실행 전 코드/입력 해시를 기록하고 결과를 본 후 이번 규칙을 조정하지 않는다.
도식 차단, 정상 표 잘못 제외, 정상 표 unknown 보류, 후보 자체 미탐을 분리한다.
전체 셀/의미 정확도 및 검색 가능 여부는 이 실험에서 검증하지 않는다.

## 첫 실행 결과 — 적용 보류

`reports/diagram-gate-20261027/run-01/comparison-reviewed.html`에 원본과 실제 판단을 보존했다.
15개 재사용 문서 382쪽, 기존 Physical 후보 586개를 읽고 허용한 393개에만 기존 의미 분석기를 실제 호출했다.
부분 Gold 16개 중 10개 계속 처리, 3개 불필요 보류, 2개 정상 서식의 도식 오인, 1개 기존 물리 셀 미복원.
도식 6구간 중 1개 도식 후보 제외, 1개 unknown 보류, 2개 미차단, 2개 후보 자체 없음.

핵심 실패: 연결선의 두 끝만 검사하므로 그 사이의 다른 셀을 구분하는 표 경계도 연결선으로 오인한다.
또한 후보 하나씩 판단하므로 여러 후보로 분리된 흐름도는 놓친다.
고립된 형태에서 통과한 합성 테스트는 이 실제 서식 오류를 검증하지 못했다.
78개 코드/회귀 테스트 통과와 별개로 문서 수준 적용 기준은 **실패**다.
기존 코드·JSON·이전 보고서 해시 변경 0. 운영 활성화 및 후속 규칙 조정은 하지 않았다.

후속 제안(미구현): 연결선 경로에 실제 표 셀/경계가 놓이는지 반증 검사, 후보 사이 관계 관찰,
병합 서식 음성 합성 사례를 추가한 별도 동결 실험. 실패한 이번 실행은 덮어쓰지 않는다.
