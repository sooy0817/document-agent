# ADR-014: Opt-in group context repair

Original IR artifacts and schema contracts are immutable. Investigation of the
reported missing amount found that it remains in a neighboring physical cell;
the reference's wide merged box bound to an empty cell instead. An initially
considered text fallback was therefore withdrawn. No extraction implementation,
OCR inference, or forced boundary merge is introduced. Reference geometry remains
unchanged pending separate review, and the diagnostic mismatch is reported.

An opt-in label-blind proposal generator detects sparse single-panel headings and
following populated rows. The next heading or merged-stub closure ends the candidate
interval. This is insufficient to prove subtotal/total semantics, so inferred,
review_required proposals remain separate from the original graph. No label/year/
page/organization constants are used. Multi-panel and multi-stub tables abstain.

Proposals bind through existing Registry / ADD-REPLACE operations / Validator.
Operation history and before/after graphs are retained. No deletion of unsupported
existing parents or invented root confirmation. Aggregation and cross-page fixes
remain pending independent evidence. Namwon metrics are development-only.
