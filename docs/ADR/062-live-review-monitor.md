# ADR-062: 실제 검토 이벤트를 보여주는 실행 현황

2026-11-04. `/monitor`는 기존 검토 큐와 판단 API를 사용하는 별도 화면이다.
2.5초마다 상태를 읽고 선택 요청의 단계 이력을 표시한다. 모델 내부 사고 과정이나 토큰별
진행률은 표시하지 않는다. 완료는 코드 실행 완료이며 의미 정확도 승인이 아니다.

실행 중/확인 필요/전체 기록, 실제 모드별 단계 흐름, 원본·관계 후보·Judge 근거,
판단 입력과 재검토 전후 비교를 연결한다. 입력 중 폴링으로 폼을 교체하지 않는다.
오래된 요청에서는 새 판단을 허용하지 않고 최신 요청으로 안내한다.

Claude 연결, 코드 자동 수정, 파서 재추출은 이 검토 흐름에서 실행되지 않는다. 화면에
실행 안 함을 표시하며 파일 목록은 단계의 구현 위치/목적이다. 실제 변경 파일/수정 작업이
있는 것처럼 표시하지 않는다. 코딩 에이전트의 실시간 작업 스트림은 범위 밖이다.

source/role/relation/Judge/validation은 실제 이벤트에 대응한다. 예산 초과·실패·취소는
남은 단계를 완료로 칠하지 않는다. 연결 실패는 이전 기록임을 표시한다. 원본·과거 결과는
읽기 전용이고 기존 사용자 판단 API만 변경을 수행한다. 모델 API 추가 호출은 버튼 동작으로만
기존 한도 내에서 실행한다. 모니터 페이지 열기 자체는 모델 호출이 아니다.
