# ADR-058: 저장 관계 조회와 원본 선행 관찰을 포함한 실험 검토

2026-11-03. 기존 파서와 문서 IR은 수정하지 않는다. `agents_v2`는 별도 검토 결과 계약이다.

## 문제와 결정

기존 검토가 이미 저장된 중첩 관계를 누락으로 주장했다. 모델이 말하는 저장 상태는
CanonicalDocument/중첩 sidecar에서 직접 조회한다. `present`, `not_found_in_snapshot`,
`unknown`을 구분하며 저장 여부는 PDF 의미 정확성의 승인이 아니다.

`collect_evidence → source_review → analyst_v2 → [expand_evidence → reanalysis] → judge_v2 → validate_review → report`.

원본 관찰은 사용자 오류 주장·분석 결과·추출 의미 관계를 받지 않는다. 다만 추출 셀을
위치 앵커로 받으므로 완전한 파서 독립 검토가 아니다. 동일 GPT-4.1의 별도 호출이다.
원본 관찰자와 분석자의 일치를 사람 Gold나 독립 모델 합의로 표현하지 않는다.

읽기 전용 도구는 원문 ID 조회, 관계 조회, 선택/인접 페이지 조회로 제한한다.
최대 2개 요청과 1회 보완/재분석만 허용한다. 기본 3회, 보완 시 4회 호출한다.
일일 예산·응답 체크포인트·불명확한 중단 시 자동 재과금 방지는 기존 구현을 재사용한다.
최소 3단계를 완료할 예산이 없으면 시작하지 않는다. 중간 추가 호출도 기존 예약 한도를 따른다.

부모 관계는 바깥 셀→내부 표, 행/열 관계는 제목 셀→값 셀로 명세한다. 존재하는 관계의
누락 주장과 존재하지 않는 관계의 저장 주장을 모두 코드로 대조한다. ID·인용·검수 대상
범위·자기 소속을 중첩 관계로 잘못 표현한 경우를 검사한다. 기하와 문맥의 의미 정답을
이 코드 검사만으로 보장하지 않는다. 누락된 근거와 자원 제한은 보류 사유로 남긴다.

## 적용 범위와 관측

큐의 `agents_v2` 명시적 실행만 추가한다. 기존 `agents` 자동 실행 설정은 유지한다.
별도 활성화 시점을 설정하지 않아 자동 모드는 전환되지 않는다. 화면에서 실험 버튼,
선행 원본 관찰, 실제 저장 조회, 추가 근거, 최종 검수·보류 사유를 확인한다.
요청당 단일 root 아래 단계별 span과 도구 span을 남기며 기존 Langfuse 마스킹을 재사용한다.
PDF 전체·이미지·키는 trace에 넣지 않고 로컬 실행 산출물에 원본/응답을 연결한다.

## 실제 결과 및 미해결

개발/회귀 문서 3건, 총 4실행, 13회 호출, 추정 $1.499488.
KB의 이미 존재한 부모 연결 누락 주장은 반증했으나, 하나은행에서는 가입대상을 열 제목으로
오해하고 저장되지 않은 경로를 저장됐다고 주장했다. 보완 조회 후에도 오해가 남았다.
초기 Judge의 잘못된 issue 생성은 정확한 대상 개수 스키마로 제한했다. 마지막 실행에서는
이 오류가 사라졌지만 근거 없는 인용/관계 주장은 여전히 발생하여 보류했다.
모든 실행이 보류된 것이 높은 정확도를 의미하지 않는다. 새 Holdout 성능은 측정하지 않았다.
따라서 실험 모드로 유지하며 자동 기본 경로로 승격하지 않는다.
