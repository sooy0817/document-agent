# ADR-063: 같은 화면의 문서 검토와 요청별 모델 고정

2026-11-04. 기존 Folio를 동일 출처 iframe으로 `/monitor` 안에 표시한다.
`embed=monitor`에서는 업로드·문서 목록·중복 큐를 숨기고 원본/문서 보기/셀 상세/HTML/JSON,
페이지 이동과 오류 담기를 재사용한다. 대시보드 폴링으로 iframe을 다시 로드하지 않는다.
요청이 바뀔 때만 문서 위치를 바꾼다. 원본과 판단 입력을 동시에 유지한다.
메뉴와 요청 목록의 원형 표시는 최신 확인 필요 건에서만 켜진다. 색상 외 건수·텍스트도 제공한다.

새 역할/관계 검토는 설정의 `model`을 요청 payload에 고정한다. 활성화 모델은
`gpt-4.1-mini-2025-04-14`. 기존 요청은 GPT-4.1로 유지하고 모델 설정 변경은
오래된 오류 담기의 재실행을 유발하지 않는다. 판단 후 만든 새 요청은 새 모델을 고정한다.
ModelCalls의 요청 해시에 모델을 포함하고 모델별 입력/캐시/출력 단가로 추정 비용을 계산한다.
알 수 없는 모델은 임의 모델로 대체하지 않는다. 모델 변경은 품질 향상 검증이 아니다.

Claude는 설치 파일만 확인했으며 인증·연결·호출은 하지 않았다.
파서/기존 JSON/동결된 역할 프롬프트는 수정하지 않는다.
