PDF를 올리고, 원문과 표를 확인하세요.

본문과 복잡한 표를 함께 분석합니다. 아래에서 문서를 선택하면 분석이 시작됩니다.

파일을 넣으면 이렇게 진행됩니다

  1. 문서 분석본문과 표의 셀·병합 구조를 추출합니다.
  2. 원문과 결과 확인아래 화면에서 페이지와 셀을 선택합니다.
  3. 임베딩·검색아래 검색 준비에서 임베딩한 뒤 질문합니다. 업로드만으로 시작되지 않습니다.

첫 테스트는 글자를 선택·복사할 수 있는 PDF로 시작하세요. 스캔·이미지의 문자 인식(OCR)은 아직 연결되어 있지 않습니다.

추출한 결과를 원문과 함께 검토하는 공간

PDF의 문자·선·좌표로 셀과 병합을 복원하고, 행열 경로와 중첩 관계를 후보로 구성합니다. 셀을 선택하면 원본 위치와 연결된 설명을 확인할 수 있습니다.

스캔 OCR은 연결되어 있지 않습니다. 질문은 문서 분석 후 검색 준비를 실행해 사용합니다. 표시되는 의미 관계는 검토가 필요한 후보이며 금융 사실로 승인된 결과가 아닙니다.

업로드 파일과 결과는 이 실행 서버의 work/document-explorer에 저장됩니다. 현재는 내 컴퓨터에서만 실행하는 데모입니다.
